# v1.5.0 验证记录

重新设计本地智能体工作台，围绕当前任务、真实结构图、节点职责与设计变化组织信息。

- 深绿导航和浅色画布，六个视图分开设计、实际成果、图、运行与交付；清晰展示当前任务。
- 15 个结构均按“接收 → 动作 → 产出”说明，实际内容和逐段代码解释继续完整展示。
- 执行流程与组成视图、节点详情及源码高亮跳转；配置修改自动切换组成图，步骤变化展示流程图。
- 真实设计变化自动生成历史与前后对照，新增/更新/移除高亮；历史对照使用对应版本，坐标移动不生成业务差异。
- 网页需求保存到本地队列，Skill 每轮读取后修改实际规范、图、契约与文件，再记录应用依据；提交需求不会伪装成已完成。
- 支持直接插入处理环节并重接连线，契约或代码未完成会明确提示并阻止不实交付。
- 移除理解检查和学习笔记；旧记录仅作历史，答题不参与继续设计或设计完成条件。
- 保留实际文件、框架轨迹、状态前后对照、文档同步、业务校验、备份与冲突保护。

验证：16 项设计/同步/需求/实际框架测试、7 项 HTTP/冲突/路径边界测试、实际成果全文/转义/旧版兼容检查、31 文件技能包校验。浏览器验证节点详情与源码高亮、需求保存及宿主修改后自动刷新、配置更新自动切图、前后图、直接新增环节、交付分组与 390px 窄屏布局，无浏览器控制台错误。框架实际执行六类业务场景和动态工具循环；模型为模拟，真实模型质量未测试。

仍然只需安装 Skill，工作台内置；网页没有独立后台模型或唤醒 WorkBuddy 的接口，需求需在下一轮 Skill 调用时处理。start_workbench.py 与 v1.3.0 相同；第 8 项 WorkBuddy 真机环境由使用者测试。
