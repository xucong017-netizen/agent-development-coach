# v1.6.0 验证记录

增加逐步开发需要的局部流程与整体结构定位，让学员能看清每个结构控制什么、作用在哪里及内部怎样工作。

- 本步局部 / 整体流程切换，红色标出同一结构的实际作用节点和受控连线，虚线表示局部图中的前后衔接。
- 显示实际设计决定、控制规则、对应节点、本步最近相关业务变化、读写字段和实现入口。
- 内部教学图拆解参数、工具调用、结果返回与异常处理；不冒充额外运行节点。
- 配置可关联多个真实节点，跨整体结构标明范围；明确不采用与对应关系缺失分别显示，不根据示例节点名猜测。
- 设计变动后按同一规范刷新两种图；历史版本对照只显示历史变化，不套用当前范围。展示映射变化不影响实际执行哈希。
- 继续保留统一 15 步与双向进度同步、自动启动、草稿/冲突保护、实际文件和真实框架执行证据。

更新后在原项目调用：“使用 agent-development-coach，继续当前项目，补齐每一步的局部流程、控制规则和整体对应关系，更新设计台。”打开 Skill 自动返回的最新地址。

验证：10 项结构映射测试；原 16 项设计/真实框架测试与 8 项双向步骤同步测试；7 项 HTTP/文件边界测试；9 项成果展示检查；34 个技能资源校验；隔离文档渲染检查全部 15 结构、范围切换、组成视图、未采用状态和历史分离。实际浏览器检查工具局部与整体红色定位、内部工具调用/异常分支、未采用记忆状态和提示词模型对应。真实框架搭配模拟模型；WorkBuddy 真机授课与真实模型质量未测试。用户自行测试的第 8 项启动集成保持不变。
