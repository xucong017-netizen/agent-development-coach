# 本地教学工作台

用独立 HTML 界面承载整个开发过程。项目仍保存在学员选择的目录；工作台直接读取实际文件，修改保存写回原项目。Python 3.10+ 标准库即可启动，无需安装网页框架或模型 SDK。

## 启动

初始化或恢复 `agent-design/teaching-state.json` 后，优先启动：

```text
python "<技能目录>/scripts/workbench.py" --project "<项目目录>" --port 8766 --open
```

在宿主支持的持续终端或后台进程中运行，记录返回的真实地址。网页默认地址 `http://127.0.0.1:8766`，只供同一台电脑浏览。已有服务时先核对 `/api/snapshot` 的 `project_path` 是否为当前项目，再复用；端口被其他程序占用则换 `--port 8767`。不改动其他进程。打开网页使用宿主提供的浏览器能力；不假定有特定插件。

Windows 手动运行也可以使用命令。窗口需保持运行；Ctrl+C 停止。不具备持续运行能力时导出独立副本，并明确它不能直接同步文件：

```text
python "<技能目录>/scripts/workbench.py" --project "<项目目录>" --export "<项目目录>/agent-design/workbench-snapshot.html"
```

导出文件建议保存在项目之外，避免将大型旧 HTML 副本反复纳入下一次导出。纯 HTML 副本可以浏览、编辑浏览器草稿、导出 JSON/单个文件；真正写回项目需要本地服务。导入进度只导入 state，不自动覆盖导出包中的代码。

## 每一步怎样同步

1. 开始本轮、继续课程或收到“网页已修改”时，重新读取进度和相关实际文件。不能用聊天记忆覆盖网页保存的内容。
2. 写业务正文/代码后，读回文件，再更新本模块 `decision`、`artifacts`、`presentation_status` 和 `file_catalog`。同步局部 `graph` 与业务 `agent_graph`，解释图中对应职责。进度 JSON 尽量写临时文件后原子替换；中间写坏时页面保留已有内容并提示。
3. 工作台约每 2.5 秒检查文件变化，无草稿时自动显示新内容；有草稿时保留编辑并提示新成果。聊天仍讲清本次改变，给出工作台的视图/模块位置。
4. 网页保存原文件备份到项目 `.workbench/backups/`，记录网页写入时间。修改代码会将关联成果标记为需复核；复核时读实际文件、重写讲解并运行适当检查，更新 `verification` 与 `outdated=false`。已经失效的执行结果不能当成新版本的运行证明。
5. 网页的“当前决定”保存到进度 JSON；教练随后把采纳的决定同步到设计正文、契约、图和实现。直接修改文档可在“文件与代码”编辑。架构编辑保存的是设计图，不自动编译为 LangGraph 代码；教练根据修改检查契约和路径后再实现。

## 信息覆盖

- 结构课堂：15 个结构的职责、组成、局部图、自然语言决定、学习笔记、实际正文/代码、分块解释、检查与结果、理解题。
- 文件与代码：扫描实际项目中的文本文件，显示内容、职责、调用关系、Python 函数/类位置，可编辑内容和用途说明。未登记用途的文件要求补讲，不假造。支持搜索与单文件导出。
- 架构地图：业务节点、边、条件与相关源文件。可改名称/职责、增删节点与连线、拖动位置，保存后标记相关结构需复核。
- 运行演练：按已记录 `trace` 回放节点，显示输入、更新、输出、依据和累计更新；区分真实执行与模拟，不调用模型。
- 项目全貌：设计与讲解进度分别统计，全部文件表、整体决定、代码验证状态、未决项、网页保存记录和完整进度 JSON。

扫描忽略隐藏文件、Git、虚拟环境、依赖目录及工作台备份；单个可编辑 UTF-8 文本文件上限 2 MB。图片/PDF/二进制文件当前不在文件编辑视图。密钥按原有要求使用环境变量，不写入教学进度和展示数据。

## 课堂打断与恢复

浏览模块不意味着完成；“记录为已讲解”只改变展示记录，设计检查仍由教练完成。网页修改后不直接推进下一步。先解释改变对输入输出、文件和图的影响，再按当前模块检查。旧版 schema_version=1 可直接读取；缺失展示字段按待展示补充。

示例包含 15 个设计段落和可实际运行的课程查询函数，模型、LangGraph 流程与轨迹为待接入或模拟，不代表完整真实智能体已运行。
